# Pannenkoekenmonster Speurtocht

GPS-speurtocht (web app, één HTML-bestand) voor een kinderfeestje. Toont alleen de volgende stop, ontgrendelt de puzzel via geofencing en laat de kinderen de delen van het Pannenkoekenmonster verzamelen.

- `index.html` – de complete app (Leaflet + OpenStreetMap voor de kaart).
- Instellen in de app via ⚙︎ (pincode) → stops op de kaart kiezen of met GPS vastleggen → deel-link kopiëren.
